# Privacy and Security

## Privacy modes

### Local Only

- all events and analysis remain on device;
- local model optional;
- no account required;
- no cloud dashboard.

### Hybrid

- local collection and redaction;
- selected metadata synced;
- managed or BYOI analysis;
- cross-device reports.

### Enterprise

- configurable data residency;
- customer-managed keys;
- retention controls;
- private endpoints;
- self-hosted or dedicated inference options.

## Default guarantees

- source code is not uploaded by default;
- prompts are not synced by default;
- secrets are redacted locally;
- telemetry is opt-in and documented;
- collected fields are visible to users.

## Security controls

- encryption in transit and at rest;
- local secret scanning;
- least-privilege tokens;
- signed releases;
- dependency provenance;
- audit logs;
- enterprise policy enforcement.

## Trust strategy

Open-source collectors and schemas allow users to verify what leaves the machine.
