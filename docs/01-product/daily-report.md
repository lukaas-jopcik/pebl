# Daily AI Performance Report

## Goal

Give the user a clear end-of-day answer to:

> Did I collaborate with AI better today?

## Report structure

### Summary

- meaningful interactions;
- completed work clusters;
- successful first attempts;
- verified outcomes;
- estimated time saved;
- estimated avoidable effort.

### Progress

- prompt completeness trend;
- retry trend;
- verification habit;
- planning habit;
- project-context reuse.

### Coaching

- biggest improvement;
- most common issue;
- one recommendation for tomorrow.

## Tone

Supportive and factual.

Bad:

> You wasted 80,000 tokens.

Good:

> Two tasks repeated project discovery because the test framework was not included in context. Saving this rule may reduce future setup work.

## Enterprise constraint

Reports must never become employee surveillance. Raw productivity rankings and simplistic cost leaderboards are explicit non-goals.
