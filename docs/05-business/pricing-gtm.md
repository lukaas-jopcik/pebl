# Pricing and Go-to-Market

## Free / Open Source

- local collection;
- local receipts;
- basic daily report;
- one-device history;
- BYOI support.

## Pro

Target range: $12–20/month.

- managed analysis;
- cross-device sync;
- advanced receipts;
- long-term progress;
- reusable prompt and memory suggestions;
- project comparisons.

## Teams

Target range: $25–50/user/month or usage-based hybrid.

- shared Project Memory;
- team playbooks;
- aggregate workflow intelligence;
- policies;
- centralized billing.

## Enterprise

Annual contracts with:

- SSO/SAML;
- audit logs;
- data residency;
- private deployment;
- advanced retention;
- support and security review.

1. GitHub open-source launch
2. Claude Code communities
3. Hacker News
4. Reddit developer communities
5. X and LinkedIn build-in-public content
6. Product Hunt after validated onboarding
