# Founder Manifesto

AI systems improve rapidly. The people using them rarely receive equivalent feedback.

A developer can complete ten times more work with an agent while becoming less aware of how decisions were made, where effort was wasted, and which working habits produce reliable outcomes. Companies can see token consumption, but they cannot see whether collaboration quality is improving.

Pebl exists to close that loop.

We believe:

- AI should increase human capability, not create passive dependency.
- Every interaction can produce a reusable lesson.
- The best coach is present at the moment of work, not in a separate course.
- Improvement should be measured against the user's own baseline.
- Privacy must be structural, not contractual.
- Good coaching is specific, evidence-based, and non-judgmental.

Pebl does not optimize the model. Pebl improves the operator, the project, and eventually the organization.

**Every prompt. A better you.**
