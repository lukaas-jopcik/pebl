# AI Coach Engine

## Objective

Generate the smallest high-confidence intervention that improves future Human × AI collaboration.

## Pipeline

1. Detect meaningful interaction.
2. Extract deterministic evidence.
3. Identify candidate inefficiencies.
4. Compare against personal or project baseline.
5. Rank candidate insights.
6. Generate one recommendation.
7. Validate recommendation against evidence.
8. Store user response and downstream outcome.

## Insight categories

- missing context;
- missing constraints;
- unclear acceptance criteria;
- oversized scope;
- avoidable correction loop;
- repeated project discovery;
- insufficient verification;
- model mismatch;
- unnecessary premium-model usage;
- effective planning pattern;
- reusable project learning.

## Confidence

High: multiple direct signals support the claim.

Medium: one strong signal or several indirect signals.

Low: speculative; do not surface automatically.

## Senior-user value

Senior users receive decision-level feedback rather than definitions:

- alternative architecture trade-offs;
- repeated discovery and documentation gaps;
- unnecessary complexity;
- weak verification;
- context packaging;
- model and workflow routing;
- reusable team patterns.
