# Prompt Quality Engine

## Goal

Measure prompt readiness without pretending that length equals quality.

## Dimensions

- intent clarity;
- relevant context;
- constraints;
- acceptance criteria;
- scope control;
- verification plan;
- project alignment;
- ambiguity;
- actionability.

## Scoring philosophy

There is no universal perfect prompt.

Scores are relative to task type, project, user baseline, and observed outcome.

## Deterministic features

- presence of explicit deliverable;
- constraints and exclusions;
- success criteria;
- references to existing project conventions;
- requested verification;
- contradictory instructions;
- extremely broad scope.

## Outcome calibration

A prompt score becomes more trustworthy when connected to first-pass completion, number of corrections, abandoned paths, verification success, user acceptance, and subsequent rollback.

## User-facing output

Never show a pseudo-scientific score without explanation.

Preferred:

> Strong context and scope. Missing verification criteria.
