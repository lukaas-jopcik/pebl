# ADR-001: Automatic Work Clustering

## Status

Accepted for MVP.

## Context

Users should not manually start or finish tasks.

## Decision

Pebl infers internal Work Clusters from prompts, time, project activity, files, commands, and verification boundaries.

## Consequences

- lower user friction;
- imperfect clustering in early versions;
- receipts may initially focus on single interactions;
- clustering quality becomes an evaluation priority.
