# Contributing to Pebl

Pebl is designed as an open core project.

## Contribution principles

- Protect user privacy.
- Do not add telemetry without explicit documentation.
- Prefer deterministic analysis before adding LLM calls.
- Every coaching insight must be actionable and testable.
- Never add UX that requires users to manually start or finish work units.
- Keep integrations provider-independent.

## Initial contribution areas

- AI CLI adapters
- local event collectors
- prompt classification
- terminal UX
- anonymization utilities
- receipt rendering
- evaluation datasets
