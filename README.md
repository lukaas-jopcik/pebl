# Pebl

> **Every prompt. A better you.**

Pebl is the performance layer for people working with AI agents.

It observes Human × AI collaboration, identifies avoidable effort, creates actionable coaching, and turns every meaningful interaction into reusable improvement for the person, project, and team.

## Category

**AI Collaboration Intelligence**

Pebl is not another chatbot, code editor, prompt library, or generic analytics dashboard. It is a feedback system for the human operator behind AI.

## Initial product

The first module is an open-source terminal-first AI Coach that:

1. detects meaningful prompts automatically;
2. observes the agent run without requiring manual task management;
3. produces an AI Task Receipt;
4. identifies one high-confidence improvement;
5. stores reusable project learnings;
6. generates daily and weekly performance reports.

## Product law

> Every AI interaction should improve either the current result or the next interaction.
