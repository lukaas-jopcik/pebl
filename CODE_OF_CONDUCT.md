# Code of Conduct

Pebl is built around improvement without judgment. The community should reflect the same principle.

## Expected behavior

- Be respectful and specific.
- Critique ideas and implementations, not people.
- Protect user privacy and sensitive data.
- Assume good intent while requiring evidence.
- Make space for contributors with different experience levels.

## Unacceptable behavior

- Harassment, discrimination, or personal attacks.
- Publishing private prompts, code, credentials, or company data.
- Misrepresenting speculative analysis as fact.
- Using Pebl contribution spaces to shame or rank individuals.

Repository maintainers may remove content or participation that conflicts with these standards.
